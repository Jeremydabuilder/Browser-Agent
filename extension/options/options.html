AI companion (Groq)

Satchel uses your Groq account through a small companion program on your Windows PC. Your Groq API key is stored there, encrypted for your Windows account. It is never stored in the browser or the extension.

Checking…
How to install the companion (one time)
  1. Open the Satchel folder you downloaded, then companion → windows.
  2. Double-click install.cmd. If Windows shows “Windows protected your PC”, click More info → Run anyway.
  3. When asked, paste your Groq API key (from console.groq.com/keys) and press Enter. It is checked with Groq and then saved encrypted.
  4. Restart the browser (close every window), then press Test connection above.

To change the key later, double-click set-key.cmd. To check everything, double-click status.cmd. Nothing needs to start at login: the browser starts the companion automatically when Satchel needs it.

AI model

The list comes live from your Groq account, so retired models never appear. “Auto” picks a good available model and switches automatically if one is removed.

Groq's free tier limits tokens per minute. If you see rate-limit messages often, lower the max page text or choose a smaller model. Long pages are automatically split or trimmed to fit.

Privacy

Satchel never monitors your browsing in the background and never sends your browsing history to Groq. It only reads a page when you ask it to, and it shows what will be sent.

Google (Gmail and Classroom)

Optional. Google requires every app to have its own “OAuth client ID”. Because Satchel is your personal extension, you create a free one in your Google account (about 10 minutes, one time).

Step-by-step: create your OAuth client ID
  1. Go to console.cloud.google.com and create a project named “Satchel” (use a personal Google account if your school account cannot create projects).
  2. Open APIs & Services → Library and enable Gmail API. If you use Google Classroom, also enable Google Classroom API.
  3. Open Google Auth Platform (or OAuth consent screen). Choose External, fill in the app name and your email. Under Audience → Test users, add the Google account(s) you will connect.
  4. Open Clients (or Credentials → Create credentials → OAuth client ID). Application type: Web application.
  5. Under Authorized redirect URIs, add exactly: …
  6. Create it, copy the Client ID (ends with .apps.googleusercontent.com) and paste it below.

While the app is in “Testing”, Google shows an “unverified app” screen. That is expected for a personal app; click Continue. School accounts: many schools only allow apps approved by their Google administrator. If you see “Access blocked” or “admin_policy_enforced”, ask school IT to allow the client ID, or connect a personal account instead. The rest of Satchel works either way.
