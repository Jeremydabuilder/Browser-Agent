Add Satchel to your browser

The Satchel companion is installed. One last step: load the extension in Chrome or Edge. It takes about a minute, and you only do it once.

  1. Open a new tab, paste this into the address bar, and press Enter:
    edge://extensions
  2. In the left menu, turn on Developer mode.At the top right, turn on Developer mode.
  3. Click Load unpacked. In the folder window, paste this path into the address bar at the top, press Enter, then click Select Folder:
    %LOCALAPPDATA%\Satchel\extension

    Satchel appears in the list with the ID enhkjfoecodefiigkephlalmoebbfgmb. The companion only answers that ID.

  4. Click the puzzle-piece Extensions button in the toolbar, then the eye icon next to Satchel to keep it visible.Click the puzzle-piece Extensions button in the toolbar, then the pin next to Satchel.
  5. Close every Edge window and open Edge again. This is needed once so the browser finds the companion.
  6. Click the Satchel icon (or press Alt+Shift+S). The sidebar opens. When the top says AI: ready · Groq, you're done. If it doesn't, the sidebar shows exactly what's missing.
If a message about developer mode extensions appears when the browser starts, choose to keep Satchel. It appears because Satchel is loaded from this PC instead of an extension store.

Good to know

  • You never need to start the companion. The browser starts it by itself when Satchel needs the AI, and it closes again afterwards.
  • Your API keys stay encrypted in %LOCALAPPDATA%\Satchel for your Windows account. They are never put in the browser.
  • Start menu → Satchel has shortcuts to set your Groq or OpenAI key, check the companion, reopen this guide, and uninstall.
  • To update Satchel, run the newer SatchelSetup.exe, then restart the browser.
